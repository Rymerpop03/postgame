Content filter — test suite

Runs against the real js/moderation.js. Every case is checked through the same public functions the site uses: check() for prose, checkName() for handles and display names, and mask() for what actually reaches the page. Reload to re-run.

Inputs for the blocked cases are stored base64-encoded and decoded at run time, for the same reason the filter's own word list is hashed: a test file should not be a readable list of slurs. Each case is described by what it tests rather than by its content, and the failing-case output redacts the input too — a failure tells you which rule broke, which is the part you need.
